### Feature: "Member Contacts" Export

**Privacy-First:**
```javascript
// Only share if members opted in
members.filter(m => m.share_contact === true).map(m => ({
  name: m.name,
  email: m.email_public, // Different from login email
  social: m.social_handles,
  permission: "shared_with_squad_members"
}))
```

### Feature: "Reputation Token" System

**Blockchain-style verification:**
```javascript
ReputationToken {
  id: "ASQ-BOB-20250630",
  member: "u_bob",
  squad: "squad-001",
  metrics: {
    duration: 180,
    attendance: 85,
    contributions: 2500
  },
  verified_by: "squad-001-owner",
  timestamp: "2025-06-30T00:00:00Z",
  signature: "sha256-hash", // Prevents forgery
  valid: true
}
```
