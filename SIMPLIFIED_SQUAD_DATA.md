## 👥 Reforming Squads (In-App Only)

### Simple Flow: Use Member IDs

**When squad is deleted, you see:**

```
┌─────────────────────────────────────┐
│ Alpha Squad Members                 │
├─────────────────────────────────────┤
│                                     │
│ @alice_owner  [Invite to New Squad] │
│ @bob_123      [That's you]          │
│ @carol_fit    [Invite to New Squad] │
│ @david_gym    [Invite to New Squad] │
│ @emily_run    [Invite to New Squad] │
│                                     │
│ [Create New Squad & Invite All]     │
└─────────────────────────────────────┘
```

### How It Works:

**Option 1: Individual Invites**
```
1. Click "Invite to New Squad"
2. Select your current squad from dropdown
3. ✅ In-app notification sent to @carol_fit
4. She accepts → Joins your squad
```

**Option 2: Bulk Invite**
```
1. Click "Create New Squad & Invite All"
2. Enter new squad name: "Alpha Squad 2.0"
3. ✅ All 4 members get invite notification
4. They accept → Squad reformed!
```

**Option 3: Share Squad QR Code**
```
1. Open your current squad
2. Show QR code on phone
3. Former members scan
4. ✅ They join instantly
```

## 🎮 User Flows

### Flow 1: Reform Squad After Deletion
```
1. Alpha Squad deleted by owner
2. Bob opens "Former Squads" section
3. Sees list of @usernames from Alpha Squad
4. Clicks "Create New Squad"
5. Names it "Alpha Squad 2.0"
6. Clicks "Invite Former Members"
7. Selects @carol, @david, @emily
8. ✅ In-app notifications sent
9. They accept
10. ✅ Squad reformed!
```

### Flow 2: Join New Squad with Resume
```
1. Bob applies to "Elite Warriors"

3. Shows 85% attendance, 6 months
4. Owner sees Reputation Token ⭐⭐⭐
5. ✅ Instant acceptance
6. Bob joins without trial period
```

```
1. Bob creates "Alpha Squad 2.0"
2. Opens squad → Invite tab → QR code
3. Shows phone to Carol at gym
4. Carol scans QR
5. ✅ Carol joins instantly
6. Repeat for other members
7. ✅ Squad reformed in minutes
```
